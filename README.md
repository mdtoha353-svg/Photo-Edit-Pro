# PhotoEditPro

Simple Android photo editor. GitHub Actions builds the APK automatically.

## Build APK
1. Upload this project to a GitHub repository.
2. Open **Actions**.
3. Select **Build PhotoEditPro APK**.
4. Click **Run workflow**.
5. Download the `PhotoEditPro-APK` artifact.
6. Extract the ZIP and install `app-debug.apk` on Android.
